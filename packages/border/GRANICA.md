# Granica outbound estimates

The `pl-granica-waits` feed reads one ordinary Polish [country page](https://granica.gov.pl/index.php/pl/czasy-oczekiwania/ukraina) every 1800 seconds through the existing guarded acquisition framework. It requires exactly one payload and rejects HTML larger than 2 MB at parsing. Framework egress has its existing byte/time limits, retry handling and scheduler backoff; no provider quota is asserted and no access challenge is bypassed. There are no parser HTTP calls or executed scripts.

The accepted rights basis is [dataset 1694](https://api.dane.gov.pl/1.4/datasets/1694), whose CC BY 4.0 statement covers the same numerical outbound car/truck product on the website and service. [Publisher documentation](https://granica.gov.pl/index.php/pl/pomoc/us%C5%82uga-sieciowa) confirms equivalence. Resource 19712 describes an interface and supplies no separate blanket website grant. Preserve “Ministerstwo Finansów / Krajowa Administracja Skarbowa; granica.gov.pl; converted to OpenConditions.” and the [licence](https://creativecommons.org/licenses/by/4.0/) and [disclaimer](https://creativecommons.org/licenses/by/4.0/legalcode.en#s5) links. Geometry has separate Wikidata CC0 upstream credit with revision evidence.

Only units 401030 (Medyka), 401060 (Korczowa) and 303020 (Hrebenne), PL→UA, have joins. The two stable components are passenger cars and freight vehicles/combinations with maximum permissible gross mass above 7500 kg. This preserves the [publisher's class restriction](https://granica.gov.pl/index.php/pl/komunikaty/zmiany-organizacyjne-odpraw-pojazdow-w-ruchu-towarowym-w-przejsciach-granicznych-z-ukraina). Headers are mapped by curated aliases; known excluded crossings and the bus row are recognised solely to validate structure. Unknown/duplicate references, changed class labels, missing rows, invalid waits and uncertain clocks fail the entire parse before the feature writer can withdraw anything. Gray and empty cells contribute no observation; numeric zero does. An explicit cell suspension is retained as a closed queue, without asserting facility closure or inferring openness elsewhere.

Date and crossing-specific update minute are interpreted in Europe/Warsaw at the start of that minute, supported by [Polish time rules](https://eli.gov.pl/api/acts/DU/2022/539/text.html). This is an adapter interpretation, not a provider timezone guarantee or an independently measured vehicle event. Missing, invalid, future, DST-fold and DST-gap times fail closed. A page dated differently from the retrieval's Warsaw date is rejected to avoid guessing midnight date associations. Source time plus two hours is the absolute deadline. Eight daily publications intentionally leave gaps; successful unchanged polls do not renew a reading's deadline. The storage writer already rejects older latest states, and bulk fusion now preserves explicit deadlines through API reads before cleanup. Static crossings survive those gaps.

Tests use a dated exact-byte page and explicitly synthetic mutations, then exercise worker acquisition, production sealing, PostGIS fusion and source/canonical API reads. They do not establish continuous provider stability, fresh direct Wikidata proof for every entity, native deployment, or production qualification. See the fixture receipts for reference evidence and access failures.
