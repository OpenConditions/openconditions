# NSW RFS Current Incidents

`au-nsw-rfs-alerts` reads one bounded EDXL-DE 1.0 distribution containing CAP 1.2 messages. It accepts explicit Bush Fire and Grass Fire incidents with `IsFire: Yes` and the matching CAP-AU event code. Known other incident classes count as terminal exclusions; missing or unknown semantics fail the entire poll. FuelType never determines classification. Under control remains active. CAP instructions, parameters, message identity and offset times survive conversion. The publisher-qualified incident number supplies grouping across changing message identifiers.

Only zero-radius incident circle anchors are projected. Polygons, burnt areas and warning footprints are omitted. An anchor has unknown fire extent; an “Unmapped Incident” anchor uses coarse (`low_res`) precision because RFS may place it at an LGA centre. Source geometry and incident details can update asynchronously; a CAP message time does not establish a geometry observation time. The separate warning endpoint is never acquired.

The catalogue uses the documented 30-minute cadence and a one-hour source publication freshness bound. Message expiry can shorten that bound; expiry never asserts extinguishment. Malformed, truncated, entity-bearing, foreign-namespace or partly unreadable XML fails as a whole. Native validation checks supported CAP containers, scalar fields and every parameter/event-code/geocode pair before any record is excluded or projected. Explicit redistribution restrictions in source text, including headlines, audiences and resource descriptions, reject the poll. HTTP validators and acquisition budgets remain owned by the framework. A 304 reparses held bytes to check the source clock rather than treating retrieval as publication.

The feed is enabled for qualified incident/text/anchor publication. `rfsCurrentSnapshotQualified` gates this supported mode and defaults to false for unqualified configurations. Every raw message must be validated and accounted, but `situationsComplete: false` independently denies absence-based withdrawal. Partial responses, excluded records and expired messages cannot clear missing incidents; those rows keep their original finite source-bounded expiry. Empty generations are refused. Reissued CAP message IDs update a stable publisher incident row while retaining the message ID and source times in provenance and CAP details.

The 9 November 2026 capture contains 23 CAP messages: 11 accepted bush/grass fires and 12 explicit exclusions, including two Burn off records. The retained 7 November capture has 30 messages, with 17 accepted and 13 excluded. These counts describe the publications, not a statewide census. Both generations pass acquisition/parser-child/PostGIS/API replay qualification. Full instructions, offset validity, geometry precision and rights are compared for every accepted incident. Actual RFS Update/Cancel sequences remain unobserved. Constructed lifecycle tests validate publisher, incident, reference time and acyclic graph checks; a Cancel with an absent reference target fails closed. No absence or empty-response authority is claimed.

That exact-product licence prevails over the contradictory generic unaltered-copying and commercial-distribution wording. The [feed page](https://www.rfs.nsw.gov.au/news-and-media/stay-up-to-date/feeds) distribution reservation remains relevant to access; this does not promise continued supply. The [licence](https://creativecommons.org/licenses/by/3.0/au/legalcode) permits compliant adaptation, commercial distribution and retained copies. Old warnings must remain dated. No new publisher permission is required by this accepted interpretation.

Local qualification covers this enabled bounded mode. Production deployment, sustained availability and actual publisher cancellation behavior remain separate evidence.
