# NSW RFS Current Incidents

`au-nsw-rfs-alerts` reads one bounded EDXL-DE 1.0 distribution containing CAP 1.2 messages. It accepts explicit Bush Fire and Grass Fire incidents with `IsFire: Yes` and the matching CAP-AU event code. Known other incident classes count as terminal exclusions; missing or unknown semantics fail the entire poll. FuelType never determines classification. Under control remains active. CAP instructions, parameters, message identity and offset times survive conversion. The publisher-qualified incident number supplies grouping across changing message identifiers.

Only zero-radius incident circle anchors are projected. Polygons, burnt areas and warning footprints are omitted. An anchor has unknown fire extent; an “Unmapped Incident” anchor uses coarse (`low_res`) precision because RFS may place it at an LGA centre. Source geometry and incident details can update asynchronously; a CAP message time does not establish a geometry observation time. The separate warning endpoint is never acquired.

The catalogue uses the documented 30-minute cadence and a one-hour source publication freshness bound. Message expiry can shorten that bound; expiry never asserts extinguishment. Malformed, truncated, entity-bearing, foreign-namespace or partly unreadable XML fails as a whole. Native validation checks supported CAP containers, scalar fields and every parameter/event-code/geocode pair before any record is excluded or projected. Explicit redistribution restrictions in source text, including headlines, audiences and resource descriptions, reject the poll. HTTP validators and acquisition budgets remain owned by the framework. A 304 reparses held bytes to check the source clock rather than treating retrieval as publication.

The feed remains disabled. `rfsCurrentSnapshotQualified` defaults to false, and the worker independently refuses publication when it is false, including successful subsets and empty distributions. Removing `disabled` alone cannot activate it. Available official captures do not independently establish a complete current incident population or authoritative empty/withdrawal behavior. A future qualification must document that contract before setting the flag. Counts from a single capture do not supply that evidence. The integration test explicitly sets the flag to exercise the publication path; this is constructed evidence, not live qualification. CAP Update/Cancel references are handled using the shared CAP lifecycle projection, with publisher, incident and reference-time checks and an acyclic revision graph. Equal-time acyclic references remain valid. Constructed sequences exercise this behavior; actual RFS Update/Cancel/reference sequences have not been observed and remain part of live qualification.

The accepted rights interpretation uses the [Current Incidents product's CC BY 3.0 AU grant](https://www.rfs.nsw.gov.au/fire-information/fires-near-me), corroborated by the [official Data.NSW dataset](https://www.data.nsw.gov.au/data/dataset/nsw-rural-fire-service-current-incidents-feed). That exact-product licence prevails over the contradictory generic unaltered-copying and commercial-distribution wording. The [feed page](https://www.rfs.nsw.gov.au/news-and-media/stay-up-to-date/feeds) distribution reservation remains relevant to access; this does not promise continued supply. The [licence](https://creativecommons.org/licenses/by/3.0/au/legalcode) permits compliant adaptation, commercial distribution and retained copies. Old warnings must remain dated. No new publisher permission is required by this accepted interpretation.

Retain “© State of New South Wales (NSW Rural Fire Service). For current information go to www.rfs.nsw.gov.au.”, the product and licence links, notices and modification credit. ControlAuthority identifies operational responsibility and does not establish copyright ownership. Branding, BOM products, unrelated incident classes, expressly restricted third-party material, road effects and historical backfill are outside this adapter. Existing public-egress rights filters remain in force.

The official fixture's companion provenance file records response time, source publication, HTTP validators, byte length and SHA-256. Test mutations are explicitly constructed. Neither these tests nor a populated HTTP 200 response qualify production activation, sustained availability or actual cancellation behavior.
