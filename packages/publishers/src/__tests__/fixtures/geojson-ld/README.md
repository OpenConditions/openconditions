# GeoJSON-LD context

`geojson-context.jsonld` is the GeoJSON-LD 1.1 base context (revision 2021-12-20) by Sean Gillies,
copied unchanged from https://geojson.org/geojson-ld/geojson-context.jsonld on 2026-10-16
(SHA-256 `99d140f6b704570920e6420435acecebde13e258179bda913001c383559164c3`). It is licensed under
the [Creative Commons Attribution 4.0 International License](https://creativecommons.org/licenses/by/4.0/),
as stated at https://geojson.org/geojson-ld/ and in https://github.com/geojson/geojson-ld.

The JSON-LD test serves it to the processor in place of the remote context the GeoJSON-LD emitters
reference, so the test never fetches it.
