The NSW camera feed reads the keyed Live Traffic API
(`https://api.transport.nsw.gov.au/v1/live/cameras`), which needs an Open Data
Hub key; the keyless copy above is the same dataset in the same GeoJSON shape,
so it stands in for the keyed answer here. The image URLs pointing at
`webcams.transport.nsw.gov.au` answered with an HTML "temporarily unavailable"
page from Europe on the day of capture; the fixture only carries the URLs.

The second Overpass query, which found the ways and the hotel, was
`way["contact:webcam"](45.8,5.9,49.0,17.2)` together with
`nwr["contact:webcam"]["tourism"|"highway"|"monitoring:weather"]` over
(46.8, 10.0, 47.6, 12.5); its elements are kept unedited beside the
Innsbruck ones, under the first answer's header.
