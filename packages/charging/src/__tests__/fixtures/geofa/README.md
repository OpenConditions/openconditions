# GeoFA captures

These bounded anonymous WFS 2.0.0 captures were retrieved on 2026-11-07 from `https://geofa.geodanmark.dk/ows/fkg/fkg`, current `fkg:fkg.t_5607_ladefacilitet`, with `count=2`, `outputFormat=application/json` and `srsName=EPSG:4326` (except `unsorted25832.json`, which requests EPSG:25832). Fields outside the parser's inventory allowlist were removed; no values or geometry were invented. Credit: [@geodanmark](https://www.geodanmark.dk/home/vejledninger/vilkaar-for-data-anvendelse/), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). OpenConditions selected fields and normalized formatting.

`twoids.json` filters nonempty `internationalt_id1`; `planned.json` filters `planstatus_kode=2`; `bicycles.json` filters `tilgaengelighed_type_kode=5`; `count8.json` filters `antal_ladepunkter=8`. Other captures are unfiltered. All filters use OGC `PropertyIsEqualTo`, except the nonempty ID filter uses `PropertyIsNotEqualTo` with an empty literal. Unsorted captures exercise parsing only. Sorted bounded requests timed out during this run, so these fixtures do not qualify sorting, page caps, load, national completeness or withdrawals. Deterministic edge cases in the tests are synthetic.
