# PUN mirror inventory

`it-agid-pun-charging` reads the public Cruscotto Italia municipal mirror. The acquisition framework freezes the PUN manifest slice, validates strictly bounded `pun/<six-digit-ISTAT>.json` paths, sizes and MD5 digests, acquires every listed shard, then compares a fresh PUN manifest slice before returning the bundle. The parser repeats these checks and refuses mixed shard generations, malformed rows, conflicting EVSE IDs and empty inventory. Failed passes retain the last publication. Identical duplicates, including municipal aliases, reconcile by EVSE ID. A successful complete mirror pass can withdraw inventory absent from that mirror; it cannot establish national completeness. The source filters unresolved municipalities and coordinates.

The manifest is limited to 16 MiB, each shard to 8 MiB, the listed total to 96 MiB and the file count to 10,000. Conditional requests reuse only digest-checked cached bodies. Cache updates happen after successful publication. HTTP 429 responses back off using Retry-After or exponential delays, with three attempts. All framework calls to the configured mirror host share one process-wide queue, one connection through body consumption and at least one second between request starts. Operators must assign one acquiring worker per egress IP and include other traffic in that budget. Cross-process and unrelated clients cannot be coordinated by this library. Daily refresh allows roughly 94 minutes for the inspected 5,618 files plus transfer/backoff. The current tests use small synthetic complete manifests, not a national crawl. A full runtime pass and deployment/IP coordination remain operator qualification gates.

The parser uses source EVSE coordinates as `[longitude, latitude]` within the publisher's Italy bounds. The mirror and inspected documentation declare no CRS; this geographic interpretation remains a qualification limitation. Municipal centroid coordinates are never used. Postcodes remain strings; null values remain unknown. Only the mirror's maximum-power representative connector is emitted, with watts converted to kW; `n_connettori` never multiplies connectors. The lost connector detail is recorded in allow-listed diagnostic extras. Removed EVSEs are decommissioned, planned EVSEs remain planned, and other inventory has unknown lifecycle. Waiting validation does not imply removal. Active flags, `real_time`, snapshot dates and file generation never produce availability readings. False opening flags do not assert hours. Media, personal contacts, capabilities implying payment/authentication, tariffs and direct Cognito acquisition are excluded.

The accepted factual-inventory rights assessment combines this release with CAD Article 52 and AgID's Open Data Guidelines requirement 20; no separate private CPO contract was inspected. The parser refuses a changed source licence notice rather than extending this assessment to an unreviewed product.
