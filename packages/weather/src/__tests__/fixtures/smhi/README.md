# SMHI metobs captures

These anonymous captures use API version 1.0 and `measuringStations=core` for both station lists and latest-hour bulk responses. `provenance.json` records the exact URLs, retrieval clocks, response headers and SHA-256 of the original bytes. Files end in `.json.raw` to preserve their upstream bytes. Each parameter's `updated` and `period` fields retain publication and observation bounds; metadata modification dates are separate.

Parameters 1, 39, 6 and 12 report instantaneous temperature, dew point, humidity and visibility. Parameters 3 and 4 report ten-minute mean direction and speed; 21 reports hourly maximum gust and 7 hourly precipitation sum. Rainfall is an amount in millimetres. The parser tests construct synthetic edge cases from these envelopes; their mutations are not upstream observations.

The [product metadata](https://opendata-download-metobs.smhi.se/api/version/1.0/parameter/1/metadata.json) describes SMHI and other station networks. The [terms reviewed on 2026-11-08](https://www.smhi.se/data/om-smhis-data/villkor-for-anvandning), updated 2026-06-15, permit commercial reuse and adaptation with attribution and notice of modifications. Their [linked legal text](https://www.smhi.se/download/18.55d446f91937861d43dbc5/1734468036450/CreativeCommons-Erk%C3%A4nnande-4.0.pdf) identifies CC BY 4.0 International. Source: SMHI; normalized by OpenConditions; CC BY 4.0. [Licence](https://creativecommons.org/licenses/by/4.0/).

CORE membership is independent of station ownership. The captures retain other owners; ownership neither excludes a station nor establishes reading quality. `G` is approved and `Y` retains the supplier's questionable/unchecked flag. `R` and unknown flags are rejected and counted. Null and empty values are absent. No numeric missing-value sentinel is assumed.

The authored feed remains disabled. The worker refuses a disabled SMHI source before opening a poll or making requests. Fixture worker tests explicitly opt into a local source copy. Activation still requires a current review of all eight products and qualification of HTTP cache directives and backoff. Existing conditional requests and 600-second bulk/86400-second metadata scheduling do not establish that contract for changing server directives. No quota or freshness SLA is asserted. A membership shrink fails conservatively to preserve complete station/component metadata alongside retained observations; retiring those channels requires a coherent publication strategy before activation.
