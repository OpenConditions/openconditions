# FMI captures

`retrieval.json` records the five public FMI requests made for these fixtures on 2026-11-08 UTC, including the failed comma-separated station-metadata request (HTTP 400). Successful XML bodies are unchanged. The observation request covers two Helsinki stations for one historical hour with seven explicit parameters and EPSG:4326; `numberReturned=1` counts a coverage, containing fourteen positions. These captures do not qualify national coverage or station membership.

`properties.xml` supplies the exact channel units and statistical windows. Metadata has a daily cadence, while observations poll every 600 seconds over an overlapping 90-minute window. The provisional national plan uses three metadata network queries (121, 122, 224) daily and one observation bbox query per poll: nominally 147 requests/day before retries, redirects and other clients sharing the public IP. The configured 60/minute and 20,000/day are ceilings, not permission to consume the shared allocation. Four additional bounded national qualification reads returned a 372,753-byte observation body and metadata bodies of 465,180, 77,610 and 70,545 bytes, below the explicit 2 MB capture ceiling. They contain 187 observed FMISIDs and a 197-station metadata union; ten metadata stations have no observations in this window. Aboa is labelled Finland in metadata despite its Antarctic position and is excluded geographically. These nine total public requests are recorded in the task receipt; national captures are retained with that receipt. Membership reconciliation and sustained body/freshness qualification remain open. No routine live checker was run. Before activation, qualify national bbox axes, response bounds, network membership, excluded stations, missing stations and retry/headroom accounting. Both catalogue disablement and the format acquisition gate must be reviewed then.

Tests mutate these captures to create synthetic malformed XML, cardinality errors, missing namespaces, reordered fields, future and invalid epochs, restricted metadata, foreign and non-weather membership, corrections and empty collections. The original files remain provider evidence. Precipitation and QC are withheld pending channel-specific qualification; no trace value is converted to exact zero. Operational periods describe station lifecycle, while sample epochs determine reading freshness and expiry. Partial metadata never authorizes withdrawal.
