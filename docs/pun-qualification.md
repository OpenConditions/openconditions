# PUN inventory qualification

`it-agid-pun-charging` is enabled for the public factual GSE/MASE inventory distributed by Cruscotto Italia (AgID). Runtime scheduling and acquisition work with default settings; the former reviewed-runtime and exclusive-IP assertion flags have been removed. The feed emits EVSE identity, source coordinates, address, source-qualified CPO identity and one representative maximum-power connector. It emits no live availability observations, tariffs, payment claims, media or personal contacts. Coverage is the complete acquired mirror generation, not a national census. An inventory disappearance is withdrawal from this mirror, not evidence that a charger closed.

## Recorded full-generation qualification

On 2026-11-09, one serial public capture acquired all 5,618 manifest-listed PUN shards, checked every listed size and MD5, and matched the PUN slice before and after acquisition. Source `last_run` was `2026-11-08T07:08:35.682394+00:00`; listed shard bytes were 46,095,901. The pass made 5,620 requests, consumed 66,198,623 response-body bytes including both manifests, and took 6,732.3 seconds with no retries. These are application response-body counts, not TLS or packet-byte measurements. No documented same-product national bundle was found in the inspected public API or official repository releases.

The captured generation contains 80,313 rows and 80,265 distinct EVSE IDs: 48 identical duplicates and no conflicting IDs. The real acquisition/cache logic accepted the whole local capture; a second accepted-cache replay required two manifest requests and zero municipal requests. The actual parse worker and publication pipeline wrote all 80,265 features into disposable PG16/PostGIS, with zero rejected records and zero observations. Local public API pagination returned every source EVSE across 17 pages, with valid content hashes and the required credit. Publication took 92.4 seconds; publication and API qualification took 112.7 seconds. Parse-worker OS high-water RSS was 817,744 KiB, and the sampled test process-tree peak was 2,861,520 KiB, excluding the Docker database and unrelated processes. These local receipts do not establish production deployment, hosted CI or native container acceptance.

The [AgID transformer](https://github.com/AgID/cruscotto-italia/blob/1b8fa8544a5ef58295838c82bfa8daa13965fef1/etl/sources/pun.py) reads named latitude/longitude fields, filters geographic Italy bounds and rounds to six decimals. The public shard does not declare a formal CRS. Independent [Istat 2026 generalized administrative boundaries](https://www.istat.it/storage/cartografia/confini_amministrativi/generalizzati/2026/Limiti01012026_g.zip), under Istat's [CC BY 4.0 terms](https://www.istat.it/note-legali/), contain 80,180 of the unique source positions; all 85 others are within 205 metres of the generalized boundary. The swapped-axis counterfactual matches none. This qualifies geographic `[longitude, latitude]` interpretation without asserting a formally declared EPSG code or surveyed accuracy. The reference geometry is used for qualification and is not added to feed output.

Seven captured rows have malformed optional postal text (`1006`, `2010`, `049405`). The parser omits those postal codes publicly without padding or guessing and retains their raw text internally. Valid five-digit postcodes keep their leading zeros. Raw status, publication and extraction diagnostics remain available to the operator API with private cache headers; public projections omit the PUN diagnostic object and recompute its content hash. Public credit preserves GSE/MASE, Cruscotto Italia (AgID), the complete supplied CC BY notice and the normalization, deduplication and representative-connector transformations. The accepted [public factual-product grant](https://cruscotto-italia.dati.gov.it/api.html#condizioni) is unchanged.

## Operating budget and coordination

Acquisition allows at most 10,000 shard paths, 96 MiB listed shard bytes, 16 MiB per manifest and 8 MiB per shard. Its total budget is four hours from before the host queue, 30,006 attempted requests including retries and 384 MiB consumed response bodies including retries. Cancellation covers queue waits, pacing, requests and body reads. A failed or mixed generation never accepts staged validators or replaces last-good inventory. An accepted cached body matching the current manifest size and MD5 can be reused without another municipal request. Otherwise conditional validators are used, and any returned or 304-reused body must match the current manifest.

A filesystem lease shared by participating clients serializes every configured Cruscotto Italia endpoint through response consumption. The persistent timestamp enforces at most one request per second, including retries; it is reserved before each call and extended after headers or failure so filesystem latency cannot shorten actual request spacing. Retry-After on 429 and other failed responses, including 503, persists immediately. A cooldown exceeding the remaining acquisition budget defers the poll without another request.

The default coordination directory is `cruscotto-italia-client` beneath `OPENCONDITIONS_STATE_DIR` (`/data` in the service manifests), or `~/.cache/openconditions/cruscotto-italia-client` for local CLI use. `PUN_COORDINATION_DIR` selects an explicit shared persistent writable directory. Processes in separate containers or hosts under the same operator must share that directory when they share the request budget. Preserve `budget.json` across restarts and container replacement. A crashed lease is never expired automatically: inspect its `owner.json`, verify its owner has stopped and preserve the cooldown before removing only the `lease` directory. Corrupt state fails closed. A cooldown write failure retains the lease; repair storage and establish the provider cooldown before clearing it.

The [publisher's limits](https://cruscotto-italia.dati.gov.it/api.html#condizioni) apply per public IP: two municipal requests per second, eight data connections and blocking beyond 3,000 requests in ten minutes. They do not require exclusive IP ownership. This coordinator controls participating clients sharing its directory; it cannot discover independent NAT clients. Operators must keep aggregate traffic from other clients within the published limits or route those clients through the shared budget. No production NAT ownership is asserted by the local qualification.

## Explicit acquisition and offline replay

Ordinary `feeds:check` retains its zero-provider-call configuration skip for PUN, including the enabled entry. A skipped source is unassessed and cannot establish monitoring recovery. A deliberate new provider pass requires `pnpm exec tsx scripts/qualify-pun.ts --full-generation`; the command acquires and parses a complete generation, publishes nothing and does not accept its cache. Do not run it alongside another acquisition or as a routine liveness probe.

For sealed local evidence, run `PUN_CAPTURE_DIR=/path/to/evidence pnpm exec vitest run --project unit packages/ingest-framework/src/__tests__/pun-capture.test.ts`, then the same prefix with `pnpm exec vitest run --project integration services/ingest/src/__tests__/pun-capture.integration.test.ts`. The acquisition replay accelerates pacing while retaining real native compression, integrity and cache logic. The integration replay uses the actual parse worker and unchanged heap policy, disposable PostGIS and all public source pages. Both make zero provider requests. Ordinary verification skips this opt-in external-evidence input. Fixture, full-capture, hosted-CI and deployment evidence remain separate.
