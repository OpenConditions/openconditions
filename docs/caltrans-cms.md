# Caltrans changeable message signs

The twelve district entries read only the agency-owned [CMS product](https://cwwp2.dot.ca.gov/changeable-message-signs.html). Cameras, travel-time files, inferred closures and inferred equipment faults are outside this adapter. Each feed configures its district independently; the wire district and repeated indexes cannot identify signs reliably. Provider acquisition remains in the ingest framework. District 2 uses five-minute polling; the other districts use one minute. No numeric request quota is asserted.

A feature identity hashes the configured district and complete trimmed operational location name using SHA-256. It does not depend on array order, index uniqueness, coordinates or current message. Coordinate and index corrections preserve identity. A location-name correction creates a new identity: automatic reconciliation would risk merging different devices. Repeated names reject the whole payload, preserving last-good publication. Long-term name continuity remains unqualified. Positions outside a conservative California envelope are excluded, including placeholders and the Sacramento longitude typo; the adapter never repairs coordinates by guessing.

Each sign has one sign face and a structured display. Blank, explicitly out-of-service and unknown reporting states carry no text. Normal/flashing and extended two-page messages preserve page and line positions; a blank line is represented by a single space because the model requires nonempty localized text. The allowlisted `caltransCms` extras retain source index, configured district, raw record/message clocks, validated instants, phase fonts and phase duration. No other payload fields enter extras. Observation phenomenon time is the retrieval observation, not an assertion that the message changed then. Record modification and message change remain separate extras. Strict Los Angeles conversion accepts only one matching instant and rejects invalid dates, 1969/1970 sentinels, DST gaps and ambiguous folds.

The catalogue entries are disabled pending deployment ownership/terms recheck and sustained district source qualification. This is separate from absence authority: `caltransSnapshotQualified` is unset. Removing `disabled` alone cannot authorize withdrawal. An unqualified subset retains absent features and series; an empty, failed, ambiguous or unreadable payload preserves last-good publication. After a district has been qualified as a complete snapshot, an operator may explicitly set `caltransSnapshotQualified: true`; only an error-free parse then grants absence authority. An explicitly qualified complete-empty response can withdraw all that district's features and authorize ending its absent display series. The existing series shrink guard still requires three complete polls spanning at least ten minutes before ending a majority of series. Excluded records suppress that authority. Other providers retain their existing completeness behavior.

The [field contract](https://cwwp2.dot.ca.gov/documentation/cms/cms-field-description.html), [layout](https://cwwp2.dot.ca.gov/documentation/cms/cms-json-layout-example.html) and [reporting matrix](https://cwwp2.dot.ca.gov/documentation/cms/cms-district-reporting-matrix.html) describe source semantics. The existing `LicenseRef-Caltrans-Conditions-of-Use` applies only to agency-owned content under the July 19, 2021 [terms](https://dot.ca.gov/conditions-of-use). Preserve third-party ownership exceptions, public-egress restrictions and Caltrans credit. Local captured-fixture and disposable PostGIS/API tests establish source behavior only; they do not qualify production activation or provider uptime.
