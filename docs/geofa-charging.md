# Denmark GeoFA charging inventory

`dk-geofa-charging` reads the current GeoFA Ladefacilitet layer. It includes public records (`off_kode=1`), administratively current (`statuskode=3`) car facilities (`ladefacilitet_type_kode=1`) with public charging access (`tilgaengelighed_type_kode=1`). Physical plan status 1 is operational, 2 planned, and other values unknown. Administrative state and system-version times do not report live operation. No availability measurements, linked tariffs, media, contacts or case information are published. Coverage can omit nonmunicipal land and update schedules vary.

The parser accepts one point in a MultiPoint, in CRS84/WGS84 or checked EPSG:25832, and refuses other geometry. Administrative dates use Copenhagen midnight through the midnight after the end date, including daylight saving changes. Facility identity uses `objekt_id`; `versions_id` is provenance. All six international ID columns remain as nonfederated evidence. Only distinct named IDs agreeing with the stated point count become EVSEs. A facility plug label is assigned only when there is one EVSE and the spelling explicitly identifies Type 2. CCS alone is ambiguous. Energy use in kWh and power class never become numerical charging ratings.

The [GeoDanmark terms](https://www.geodanmark.dk/home/vejledninger/vilkaar-for-data-anvendelse/) cover GeoFA under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Records carry linked @geodanmark credit, the licence and an OpenConditions normalization notice. The linked privacy policy concerns the website and secretariat; it is not a charger-data privacy guarantee. Upstream content remains subject to ordinary default-deny rights checks.

## Acquisition gate

The catalogue is disabled pending paging and load qualification. Removing `disabled` alone cannot activate acquisition: `main.geofa.qualification` must contain a reviewed publication `count` and `sha256` calculated with `geofaDigest` over the complete projected feature set. Do not approve a digest merely because a request returned HTTP 200 or its row count matched. The review must establish the intended query scope and complete publication independently, including server caps and transaction consistency. No such national qualification was established here.

The digest pins exact source content, including versions, and ignores page boundaries and object-key ordering. This is conservative: a changed publication requires renewed qualification. It does not establish transaction safety for future generations. Ordinary checks skip the disabled feed; an enabled but unqualified feed fails before any provider request. Synthetic qualifications in tests authorize only their fixture sets.

Acquisition requests the current layer sorted by `objekt_id`, EPSG:4326, using offsets of 500, at most 100 pages, 32 MiB in total and 120 seconds. These are local bounds, not publisher quotas. Any HTTP failure, cap, duplicate/out-of-order identity, changed version or digest/count mismatch discards the whole attempt. A failed qualified generation is held behind a process-local 24-hour cooldown; a process restart clears this cooldown. A changed reviewed digest starts a new qualification. Complete empty withdrawal requires the explicit digest of the empty publication. Parser qualification and the ordinary worker shrink guards both apply; unqualified or partial answers retain the last publication.
