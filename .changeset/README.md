# Package Changesets

Only packages in [the qualified allowlist](../scripts/public-packages.json) may have notes. Run `pnpm exec changeset` and describe the consumer-visible change with a patch, minor or major bump. Do not add an empty note for internal maintenance. The initial queue is empty; installing this tooling changes no package version.

See [release information](../docs/release-information.md) for reviewed non-release explanations, product fragments and canonical version PRs.
