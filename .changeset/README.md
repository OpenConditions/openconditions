# Package Changesets

The qualified allowlist currently contains OCPI only. Authors and reviewers decide when a consumer-facing change needs a package note. Use `pnpm exec changeset` to select the public package, patch/minor/major bump and summary. Internal maintenance needs no empty bookkeeping.

See [release information](../docs/release-information.md) for source validation and canonical version preparation. These tools do not publish or tag packages.
